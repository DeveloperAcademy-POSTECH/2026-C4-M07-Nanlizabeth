# Chordly 🎸

기타 없이, 아이폰과 아이패드만으로 진짜 기타 연주를 경험하는 앱

## 프로젝트 소개

**Chordly**는 [기타 구매가 부담되어 배우기를 망설이는 사람]이 [기타 없이 기타를 연주하며 기본기를 익히는 경험]을 통해 [기타에 대한 진입장벽을 낮추고, 취미로 이어갈 수 있도록] 돕는 앱입니다.

값비싼 기타 없이도 좋아하는 곡을 실제로 연주할 수 있다는 성취감을 빠르게 얻는 것을 목표로 합니다.

## 핵심 컨셉

**두 대의 기기가 한 대의 기타가 됩니다.**

- 📱 **iPhone = 왼손** — 기타넥 위에서 코드(운지)를 잡습니다.
- 📱 **iPad = 오른손** — 스트로크(피킹/스트러밍)를 담당합니다.
- 두 기기를 **MultipeerConnectivity**로 연동해, 아이폰이 잡은 코드를 아이패드가 긁으면 실제 기타처럼 소리가 납니다.

가상 연주 모드(예습)로 기본기를 익힌 뒤, 마지막엔 방치돼 있던 실제 기타를 꺼내 "진짜 기타 모드"로 이어지는 흐름을 지향합니다.

## 기술 스택

| 영역 | 사용 기술 |
|------|-----------|
| 언어 | Swift |
| UI | SwiftUI |
| 기기 간 통신 | MultipeerConnectivity (로컬 네트워크 P2P) |
| 오디오 합성 | AVAudioEngine + AVAudioUnitSampler (SoundFont 기반) |
| 햅틱 피드백 | Core Haptics |
| 접근성 | Voice Control, 햅틱 |
| 최소 지원 | iOS 18+ / Xcode 26 |

## 아키텍처 핵심 결정

**"스트럼 → 소리" 경로에는 네트워크를 끼우지 않는다.**

음악은 어택이 수십 ms만 밀려도 손과 소리가 따로 노는 게 느껴집니다. 따라서 오디오 합성 엔진은 스트로크를 담당하는 **아이패드(연주 기기)에 둡니다.** 아이폰은 "현재 코드 상태"만 지속적으로 전송하고, 아이패드는 긁는 순간 로컬에 저장된 코드로 즉시 소리를 냅니다. 네트워크 지연이 스트럼 타이밍이 아니라 "코드가 바뀌는 순간"에만 영향을 주도록 설계합니다.

또한 아이패드 없이 **아이폰 단독 모드**로도 동작하도록 이중 구조를 기본 전제로 합니다.
