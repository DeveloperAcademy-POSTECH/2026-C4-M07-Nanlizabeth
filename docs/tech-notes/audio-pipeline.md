# 오디오 파이프라인: AVAudioEngine + AVAudioUnitSampler + SoundFont

> 이 문서는 "왜 이 기술을 골랐나"가 아니라 "이 기술이 어떻게 동작하나"를 설명하는 참고 자료입니다.
> 채택 근거는 [ADR 0002](../adr/0002-audio-engine.md) 참고.

## 핵심 개념: "재생"이 아니라 "합성"

코드별로 미리 녹음한 오디오 파일을 트는 방식은 6현을 개별 제어할 수 없고, 긁는 속도·방향에 따라 소리를 바꿀 수 없어 진짜 기타 느낌이 나지 않는다. 따라서 GuitarSync는 신디사이저처럼 "몇 번 현을, 이 세기로 울려라"라는 명령으로 소리를 **만들어내는** 방식을 쓴다.

## 신호 흐름

```
음원(Sampler) → 믹서 → [리버브 등 이펙트] → 스피커 출력
```

## 세 구성 요소

### ① AVAudioEngine — 오디오 작업 테이블
소리를 내는 부품들을 연결하고 최종 출력으로 내보내는 배선판(믹싱 콘솔).
엔진 자체는 소리를 만들지 않고, 부품들을 `attach` / `connect`로 이어 신호가 흐르게 한다.

### ② AVAudioUnitSampler — 실제로 음을 내는 악기
"몇 번 음을, 얼마나 세게 쳐라"라는 MIDI 명령을 받아 그 음을 울리는 전자 악기.

- 노트 켜기: `startNote(52, withVelocity: 100, onChannel: 0)` → 52번 음(E)을 세기 100으로 울림
- 노트 끄기: `stopNote(...)`

**스트럼의 구현 원리** — 스트럼은 결국 6개의 음을 아주 짧은 간격으로 순차적으로 켜는 것이다.
- 다운 스트로크: 저음현(6번) → 고음현(1번) 순으로 몇 ms 간격 `startNote`
- 업 스트로크: 반대 순서
- 세게 긁음: velocity 값을 높여 더 크고 밝은 소리

이 "현별 시차 + 순서 + 세기" 제어가 녹음 재생 방식으로는 불가능한 핵심 부분이다.

### ③ SoundFont (.sf2) — 악기가 쓸 음색 재료
Sampler는 빈 악기이므로 "어떤 소리로 울릴지"를 알려줘야 한다. 그 재료가 SoundFont다.
실제 악기 음을 음정별로 녹음해 묶어놓은 사운드 팩(`.sf2` 파일)으로, Sampler에 로드(`loadSoundBankInstrument(...)`)하면 노트 명령이 들어올 때 그 안의 실제 기타 샘플을 꺼내 울린다.

```
SoundFont(.sf2) → Sampler에 로드 → "기타 음색을 아는 악기"가 됨
                                      ↓
                "52번 음, 세기 100" 명령 → 진짜 기타 E음 출력
```

무료 기타 SoundFont를 구해 초기에 붙이고, 이후 GarageBand 음색이나 직접 녹음한 샘플로 교체 가능.

## 요약

| 구성 요소 | 역할 |
|-----------|------|
| AVAudioEngine | 소리 부품을 연결해 스피커로 내보내는 작업 테이블 |
| AVAudioUnitSampler | "몇 번 음을 이 세기로" 명령을 받아 음을 내는 악기 |
| SoundFont (.sf2) | 그 악기가 쓸 실제 기타 음색 샘플 모음 |

**전체 흐름:** 긁는 제스처 → 6현을 시차 두고 Sampler에 노트 명령 → 로드된 기타 SoundFont로 소리 출력
